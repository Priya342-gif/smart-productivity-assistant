📝 STEP 1: Edit the .env file

1. Open this file in any text editor:
   life-os\.env

2. Find this line:
   MONGODB_URI=mongodb://admin:<db_password>@ac-lfb2yyn...

3. Replace <db_password> with your actual MongoDB password
   (Remove the angle brackets < >)

   Example:
   If your password is: MySecretPass123
   Change to: mongodb://admin:MySecretPass123@ac-lfb2yyn...

4. Find this line:
   ANTHROPIC_API_KEY=your_claude_api_key_here

5. Replace with your actual Anthropic API key
   Get it from: https://console.anthropic.com

   Example:
   ANTHROPIC_API_KEY=sk-ant-api03-abc123xyz...

6. Save the file

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 STEP 2: Launch Life OS

Open your terminal/command prompt and run:

1. Navigate to project:
   cd life-os

2. Initialize database indexes:
   npm run init-db

   You should see:
   ✅ Connected to MongoDB
   ✅ Created text index on notes.text
   ✅ Created text index on decisions...
   🎉 Database initialization complete!

3. Start the application:
   npm run dev

   You should see:
   ✅ MongoDB connected
   🚀 Server running on port 5000
   Compiled successfully!

4. Open your browser to:
   http://localhost:3000

❓ Troubleshooting:

Problem: "MongoDB connection error"
Solution: Check your password in .env file (no angle brackets)

Problem: "Gemini API error"
Solution: Get free key at aistudio.google.com/app/apikey (no card needed!)

Problem: "Port 5000 already in use"
Solution: Run: npx kill-port 5000

Problem: Need more help?
Solution: Read START_HERE.md or MONGODB_ATLAS_SETUP.md
