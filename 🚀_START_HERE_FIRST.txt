⚡ QUICK START (If You're Impatient)

1. Open terminal in life-os folder
2. Ensure MongoDB is running
3. Edit .env file with your Anthropic API key
4. Run: npm run init-db
5. Run: npm run dev
6. Open: http://localhost:3000

✨ WHAT MAKES LIFE OS SPECIAL?

1. 🧠 DECISION MEMORY
   Bot remembers every decision with reasoning and references them later

2. ⚖️ TRADE-OFF ANALYSIS
   Every suggestion shows what you're giving up

3. 💬 COUNSELOR PERSONALITY
   Supportive, curious, non-judgmental - never guilt-trips

4. 🔥 SMART STREAKS
   Daily habit tracking with 1-day grace period

5. 📝 CONTEXT AWARE
   Bot reads your goals, notes, and past decisions before responding
