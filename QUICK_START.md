## 🎯 First Time Setup (5 Minutes)

### Step 1: Open the App
1. Go to **http://localhost:3000** in your browser
2. You'll see the login screen

### Step 2: Create Account
1. Enter your name (e.g., "Priya")
2. Enter your email
3. Click "Get Started"
4. You're in! 🎉

### Step 3: Try the Chat
1. Type a message like: **"I want to start exercising daily"**
2. The AI will respond with personalized advice
3. Click the 🔈 speaker icon to hear it read aloud
4. Try the 🎤 microphone to speak instead of typing (grant permission when asked)

### Step 4: Add Your First Goal
1. Click the **🎯 icon** in top-right corner
2. Side panel opens → You're on "Goals" tab
3. Click **"+ Add New Goal"**
4. Title: "Complete 1 lecture"
5. Why: "to improve my studies"
6. Click "Add Goal"
7. Your goal appears with a checkbox

### Step 5: Start a Focus Session
1. In the same side panel, click **"Timer"** tab
2. Select your goal from dropdown (or leave as "General Study Session")
3. Click **"Start Focus"**
4. Timer starts! Work for 25 minutes
5. When done, you'll get a 5-minute break automatically

### Step 6: Check Your Stats
1. Click **"Stats"** tab in side panel
2. See your study time for the last 10 days
3. Bar chart shows today highlighted
4. Click any bar to see details

## 🔧 Troubleshooting

**Voice input not working?**
- Grant microphone permission in browser
- Works best in Chrome/Edge
- Check browser console for errors

**Timer not saving?**
- Make sure you "Stop" the timer, don't just close the tab
- Check if backend is running (should see server logs)

**No stats showing?**
- Complete at least one focus session first
- Click "Stop" when session ends
- Refresh Stats tab

**Check-in not appearing?**
- Clear localStorage in browser (F12 → Application → Local Storage → Clear)
- Refresh page
- Check current time (6-12 AM for morning, 8 PM-6 AM for evening)
